================================================================
  CUTUPLOADER PRO v2.0 — PANDUAN LENGKAP
  Uploader video batch otomatis untuk situs CutMotions (Kwai)
================================================================

ALUR SITUS YANG DIKOTAK-KATIK OTOMATIS
--------------------------------------
Aplikasi ini mengikuti alur asli halaman CutMotions:

  [Manual sekali di awal]
  1. Login (email + kata sandi)
  2. Pilih "Versi lama" di bagian atas
  3. Klik "Rilis karya" di menu kiri
     -> masuk ke halaman "Video Bublikasikan"

  [Otomatis oleh aplikasi, tekan F6]
  FASE 1  UPLOAD  : klik "+ Tambah video" -> ketik path file
                    video di dialog Windows -> Enter -> tunggu
                    upload selesai -> ulangi untuk video
                    berikutnya (urut nama A-Z)
  FASE 2  JADWAL  : (opsional) klik radio "Jadwalkan rilis" +
                    Negara Indonesia; Zona waktu & Waktu rilis
                    diatur saat JEDA F8
  FASE 3  CAPTION : per video -> klik tombol "Edit" -> klik
                    kotak "Judul video" -> Ctrl+A -> ketik
                    caption gabungan -> klik "Konfirmasi"
  FASE 4  KIRIM   : scroll ke bawah -> klik "Kirim"

Batas situs: maksimal 20 video sekali jalan.
Batas judul video: 250 karakter.
Caption otomatis:  CAPTION DASAR - NAMA FILE  (contoh:
"#dangdut - melati", tanpa .mp4)


CARA PASANG (WINDOWS)
---------------------
Cara paling gampang:
  1. Ekstrak semua file ke satu folder, mis. D:\CutUploaderPro
  2. Klik dua kali  JALANKAN.bat
     (kalau Python/pynput belum ada, akan dicoba pasang otomatis)

Cara manual:
  1. Install Python 3.8+ dari python.org (centang "Add to PATH")
  2. Buka CMD di folder ini, jalankan:
       pip install pynput
       python cut_uploader.py

Jadi file .exe (opsional):
  - Klik dua kali  build_exe.bat  (butuh internet untuk PyInstaller)
  - Hasil: dist\cut_uploader.exe


LANGKAH PERTAMA KALI (SEKALI SAJA)
----------------------------------
1. Buka aplikasi -> bagian 1 -> "+ TAMBAH BROWSER"
   (mis. "Chrome Akun 1"), lalu pilih FOLDER VIDEO-nya.
2. Buka browser -> login CutMotions -> Versi lama -> Rilis karya.
   Pastikan jendela browser TIDAK dipindah/resize lagi setelah ini.
3. Ambil 9 posisi klik di bagian 3. Klik AMBIL, lalu dalam 5 detik
   arahkan mouse ke target dan diamkan:

   Slot  Diarahkan ke                              Kondisi halaman
   ----  ----------------------------------------  -------------------------------
   A     Tombol "+ Tambah video"                   halaman Rilis karya biasa
   B     Tombol "Edit" baris video TERATAS         baris teratas TERTUTUP
                                                   (tulisan Edit terlihat)
   C     Kotak "Judul video"                       baris teratas TERBUKA
                                                   (klik dulu Edit-nya manual)
   D     Tombol "Konfirmasi"                       masih dalam keadaan terbuka
   E     Tombol "Kirim"                            scroll halaman sampai BAWAH
   F     Radio "Jadwalkan rilis"                   (opsional, jadwal otomatis)
   G     Dropdown "Negara"                         (opsional, jadwal otomatis)
   H     Item "Indonesia" di dropdown              (opsional; ambil saat
                                                   dropdown terbuka)
   I     Tombol "Batal"                            (opsional; isi HANYA kalau
                                                   setelah tambah video
                                                   editor-nya terbuka sendiri)

   WAJIB: A, B, C, D, E.  F/G/H hanya kalau pakai mode jadwal
   OTOMATIS.  I boleh dikosongkan.

RAHASIA TRIK POSISI B/C/D:
   Setelah satu video di-Konfirmasi, baris video berikutnya NAIK
   ke posisi yang sama. Jadi cukup SATU set posisi B/C/D untuk
   semua video (1, 5, 10, sampai 20 video pun tetap pas),
   selama tinggi tiap baris video sama dan halaman terlihat dari
   baris teratas. Kalau videonya banyak, kecilkan zoom browser
   (Ctrl + tanda minus) supaya semua baris muat tanpa scroll.


MODE JADWAL RILIS (BAGIAN 5)
----------------------------
Isi halaman "Bublikasikan aturan": pilih "Jadwalkan rilis",
Negara = Indonesia, Zona waktu, dan Waktu rilis (tanggal-jam).

Mode 1 — MANUAL (paling aman, default):
  - Centang "Jeda F8". Aplikasi akan:
    upload semua video -> BERHENTI SEBENTAR -> kamu atur sendiri
    jadwalnya di browser -> tekan F8 -> caption dijalankan ->
    Kirim.
  - Atau atur jadwalnya SEBELUM menekan F6 lalu matikan jeda F8.

Mode 2 — OTOMATIS (butuh posisi F, G, H):
  - Aplikasi klik radio "Jadwalkan rilis" + dropdown Negara +
    item Indonesia secara otomatis.
  - Zona waktu & tanggal tetap disarankan diisi saat jeda F8
    (kalendernya sulit diklik otomatis).


CARA PAKAI SETIAP HARI
----------------------
1. Buka aplikasi, pilih browser + folder video, isi JUMLAH
   (maks 20) dan CAPTION DASAR.
2. Buka browser: pastikan sudah login, Versi lama, halaman
   "Rilis karya" (Video Bublikasikan), dan posisi jendela browser
   SAMA seperti saat ambil posisi.
3. Klik MULAI (atau F6). Aplikasi bekerja 4 fase di atas.
   Jangan sentuh mouse/keyboard sampai selesai.
4. Hotkey: F6 = mulai | F7 / ESC = berhenti | F8 = lanjut dari
   jeda jadwal.

Tombol "Kirim" otomatis: kalau dicentang, aplikasi langsung
mengklik Kirim setelah semua caption selesai. Matikan centangnya
kalau mau mengecek dulu secara manual.


RIWAYAT & ANTI-DOBEL UPLOAD
---------------------------
- Setiap video yang selesai diupload dicatat otomatis di
  cutuploader_riwayat.json (per browser + folder).
- Kalau ada video yang sudah pernah terupload, video itu
  DILEWATI pada eksekusi berikutnya (centang "Lewati video yang
  sudah pernah terupload").
- Mau upload ulang video yang sama? Klik "Bersihkan riwayat
  browser ini" dulu.
- Dihentikan di tengah jalan (F7)? Jalankan F6 lagi — upload
  bersambung dari video yang belum terupload, dan caption
  diulang dari baris teratas (caption yang sudah jadi otomatis
  ditimpa dengan isian yang sama, jadi aman).
- Catatan: kalau berhenti SAAT FASE UPLOAD, urutan caption pada
  eksekusi lanjutan bisa tidak pas dengan urutan baris. Paling
  aman: hapus video yang sudah masuk daftar di situs + bersihkan
  riwayat, lalu ulangi dari awal. Atau lanjutkan saja dan koreksi
  judul yang meleset lewat tombol Edit secara manual.


PENGATURAN WAKTU (BAGIAN 4)
---------------------------
- MUNDUR SEBELUM MULAI      : persiapan pindah ke jendela browser
                              (default 5 detik)
- JEDA BUKA DIALOG/EDITOR   : tunggu dialog pilih file Windows /
                              editor video terbuka (default 2)
- JEDA ANTAR LANGKAH        : jeda klik-ketik di situs (default 1)
- TUNGGU UPLOAD PER VIDEO   : menunggu 1 video selesai terupload
                              sebelum menambah video berikutnya
                              (default 60 detik; naikkan kalau
                              video besar / internet lambat)

Semua pengaturan tersimpan otomatis di cutuploader_settings.json.


TIPS PENTING
------------
- UJI DULU DENGAN JUMLAH = 1 sampai lancar, baru naik ke 5/10/20.
- Jangan pindahkan/resize jendela browser setelah ambil posisi.
- Jangan gunakan mouse/keyboard saat aplikasi berjalan.
- Zoom out browser (Ctrl + minus) bila videonya banyak supaya
  baris teratas tetap terlihat.
- "Menyisipkan link pendek" tidak diisi otomatis (kosong).
- Judul di batas 250 karakter: pratinjau akan berwarna MERAH bila
  melebihi; aplikasi juga memperingatkan saat MULAI.


TROUBLESHOOTING
---------------
- "pynput belum terpasang"  -> pip install pynput
- Klik meleset              -> ambil ulang posisi; pastikan jendela
                              browser & zoom tidak berubah; layar
                              tidak boleh ganti resolusi.
- Upload berulang terus     -> riwayat tidak sinkron; bersihkan
                              riwayat, hapus daftar video di situs,
                              ulangi.
- Dialog file tidak terbuka -> naikkan JEDA BUKA DIALOG/EDITOR.
- Video gagal masuk semua   -> naikkan TUNGGU UPLOAD PER VIDEO.
- Antivirus curiga pada exe -> ini normal untuk hasil PyInstaller;
                              tambahkan pengecualian / jalankan versi
                              Python saja.
