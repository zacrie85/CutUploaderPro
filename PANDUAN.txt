1. CARA PASANG DI WINDOWS (TANPA PYTHON!)
------------------------------------------------------------
Ada 3 cara, pilih yang paling gampang:

CARA A - INSTALLER (paling gampang, seperti aplikasi biasa):
  1. Buka  https://github.com/zacrie85/CutUploaderPro/releases
  2. Download  CutUploaderPro-Setup.exe  (rilis v5.0 ke atas)
  3. Kalau muncul biru "Windows protected your PC", klik
     "More info" -> "Run anyway" (ini normal untuk aplikasi
     tanpa tanda tangan digital berbayar).
  4. Next -> Next -> Install -> Finish.
  5. Shortcut otomatis muncul di Start Menu dan Desktop.
  6. Mau dihapus? Lewat Control Panel > Uninstall a program.

CARA B - EXE PORTABEL (tanpa install):
  1. Dari halaman rilis yang sama, download CutUploaderPro.exe
  2. Simpan di folder mana saja, double-click. Selesai.

CARA C - PAKAI PYTHON (untuk yang sudah paham Python):
  1. Install Python (centang "Add Python to PATH")
  2. Double-click JALANKAN.bat  (library dipasang otomatis)
  File EXE/Setup SUDAH menyatukan semua library, jadi cara A/B
  tidak butuh apa-apa lagi.

2. DUA MODE DALAM SATU APLIKASI (BARU DI V5.0)
------------------------------------------------------------
Saat dibuka, di bagian atas ada DUA TAB:

  [ STUDIO MAKRO (alur bebas) ]  [ ALUR CUTMOTIONS (A-J) ]

1) STUDIO MAKRO - seperti Jitbit Macro Recorder sungguhan:
   SEMUA jenis aksi jadi MENU tersendiri di bagian atas
   (Klik titik, Jeda, Cari Gambar, Ketik Teks, Tekan Tombol,
   Scroll, Catatan, Ulangi), dan di bawahnya ADA TABEL
   KOSONG. Anda menyusun alur kerja klik-per-klik sendiri,
   satu langkah satu langkah, sesuai kebutuhan apa saja
   (tidak harus CutMotions - bisa login situs lain, aplikasi
   Windows, apa pun yang berulang).

2) ALUR CUTMOTIONS (A-J) - alur otomatis khusus uploader
   CutMotions seperti versi-versi sebelumnya (jadwal, tambah
   video, caption per baris, submit). Semua pengaturan lama
   Anda tetap ada dan tidak berubah.

Hotkey berlaku untuk tab yang SEDANG AKTIF:
  F6 = Mulai      F7 / ESC = Berhenti
  F8 / ESC = Berhenti MEREKAM (saat mode REKAM AKSI)

3. STUDIO MAKRO - SUSUN ALUR SENDIRI (BARU DI V5.0)
------------------------------------------------------------
Tampilannya persis konsep Jitbit yang Anda minta:
  - BAGIAN ATAS : semua menu langkah (2 baris tombol)
  - BAGIAN BAWAH: tabel ALUR KERJA (mulai kosong) + panel
    PROPERTI LANGKAH untuk baris yang diklik

CARA PAKAI (contoh):
  1. Klik tombol "+ CARI GAMBAR"  -> baris baru muncul di
     tabel.
  2. Klik barisnya -> panel PROPERTI terbuka di bawah.
  3. Isi POSISI X,Y (AMBIL 5 dtk atau ketik manual), POTONG
     GAMBAR, pilih "Saat ketemu: Klik di gambar".
  4. Klik "+ KETIK" untuk menambah langkah mengetik, isi
     teksnya, centang "Ctrl+A dulu" bila perlu menimpa.
  5. Tambahkan "+ JEDA", "+ TOMBOL" (Enter/Tab/panah), dst
     sampai alurnya utuh.
  6. Tekan F6 (atau JALANKAN) -> alur dijalankan urut dari
     atas ke bawah.

MENUIS LANGKAH DI TOOLBAR ATAS (baris pertama):
  ● REKAM AKSI    (v5.4) MEREKAM langsung: klik/ketikan/
                  scroll Anda direkam OTOMATIS jadi langkah
                  (lihat blok BARU DI V5.4 di bawah)
  + KLIK          klik kiri/kanan/dobel di satu titik
                  (bisa diulang, ada jeda antar klik)
  + JEDA          tunggu beberapa detik
  + CARI GAMBAR   cari potongan gambar di layar; TIDAK PERLU
                  mengisi X,Y lagi (v5.3) - gambar dicari di
                  AREA FOKUS (opsional, diseret di layar) atau
                  seluruh layar, lalu LANGSUNG DIKLIK atau hanya
                  DIPINDAH tanpa klik; kalau tidak ketemu:
                  klik tengah area / lewati / stop
  + KETIK         mengetik teks (opsional Ctrl+A dulu dan
                  Enter setelahnya)
  + TANGGAL-JAM   (v5.2) mengisi kolom TANGGAL & JAM RILIS
                  secara otomatis: nilainya diambil dari
                  kolom tanggal di tab Alur CutMotions,
                  atau diketik tetap di langkah ini
  + VIDEO+CAPTION (v5.2) mengisi dengan data video secara
                  otomatis: JUMLAH VIDEO, atau CAPTION DASAR
                  + NAMA VIDEO ke-i (mis. "#dangdut -
                  melati"), atau nama video saja
  + TOMBOL        menekan tombol keyboard: Enter, Tab, Esc,
                  Spasi, panah, Shift+Panah Bawah, Ctrl+A,
                  Ctrl+C/V, F2/F4/F5, atau 1 huruf apa saja
  + SCROLL        menggulung roda mouse Naik/Turun sejumlah
                  gulungan
  + CATATAN       penanda/komentar saja (tidak dieksekusi)
  + ULANGI MULAI  pembuka blok pengulangan
  + ULANGI AKHIR  penutup blok pengulangan

TOMBOL SUNTING (baris kedua toolbar):
  SALIN (Ctrl+C) - kop semua isi langkah terpilih
  TEMPEL (Ctrl+V) - sisipkan salinan SETELAH baris terpilih;
    semua parameternya ikut, tinggal Anda ubah sedikit ->
    inilah cara gampang membuat "titik klik berikutnya"
  HAPUS (Del) - hapus langkah terpilih
  NAIK / TURUN - geser urutan langkah
  AKTIF / MATI - matikan langkah tanpa menghapus (dilewati
    saat jalan; barisnya jadi abu-abu "(nonaktif)")
  Klik kanan baris juga memunculkan menu yang sama.

PANEL PROPERTI LANGKAH (menyesuaikan jenis langkah):
  Semua langkah punya: NAMA LANGKAH (bebas, mis. "klik
  tombol login"), JEDA SEBELUM LANGKAH (detik), dan
  centang LANGKAH AKTIF.
  - KLIK     : POSISI X,Y (+ AMBIL 5 dtk / LIHAT), JENIS
               KLIK (kiri/kanan/dobel), JUMLAH KLIK, JEDA
               ANTAR KLIK, GESER PER PUTARAN ULANGI (px).
  - JEDA     : TUNGGU BERAPA DETIK.
  - CARI GAMBAR: GAMBAR REFERENSI (PILIH/POTONG), AREA FOKUS
               (opsional - PILIH AREA FOKUS = seret kotak di
               layar; kosong = seluruh layar), SAAT KETEMU (Klik
               di gambar / Pindah saja), SAAT TIDAK KETEMU
               (Klik tengah area / Lewati langkah / Stop alur),
               KEMIRIPAN, TES CARI LANGKAH INI. TIDAK ADA lagi
               isian POSISI X,Y - kini otomatis.
  - KETIK    : TEKS YANG DIKETIK + placeholder (lihat di
               bawah), Ctrl+A dulu, Enter setelahnya.
  - ISI TANGGAL-JAM: POSISI KLIK DULU (opsional - kosongkan
               bila cursor sudah di kolomnya), AMBIL NILAI
               DARI (Tab CutMotions / Tetap), TANGGAL & JAM
               RILIS, Ctrl+A dulu, Enter setelahnya.
  - ISI VIDEO & CAPTION: POSISI KLIK DULU (opsional), YANG
               DIKETIK OTOMATIS (Jumlah video / Caption dasar
               + nama video / Nama video saja / Teks sendiri
               + placeholder), Ctrl+A dulu, Enter setelahnya.
  - TOMBOL   : pilih tombol dari daftar atau ketik 1 huruf,
               JUMLAH TEKAN, JEDA ANTAR TEKAN.
  - SCROLL   : ARAH (Turun/Naik), JUMLAH GULUNGAN.
  - ULANGI MULAI: JUMLAH ULANGAN, atau centang "Ikut JUMLAH
               VIDEO di tab Alur CutMotions".

BLOK ULANGI (mengulang sepotong alur):
  Letakkan langkah-langkah yang mau diulang DI ANTARA
  "ULANGI MULAI" dan "ULANGI AKHIR". Contoh: klik Edit ->
  ketik caption -> klik Konfirmasi, diulang 20x. Isi
  JUMLAH ULANGAN pada ULANGI MULAI. Blok boleh bersarang
  (loop di dalam loop).
  GESER PER PUTARAN ULANGI pada langkah KLIK di dalam blok
  membuat klik turun ke baris berikutnya: isi jarak antar
  baris (mis. 85) -> putaran ke-1 klik di Y asli, putaran
  ke-2 turun 85 px, putaran ke-3 turun 170 px, dst.

PLACEHOLDER UNTUK KETIK (otomatis mengikuti video):
  {caption} = caption dasar + nama video ke-i (mis.
              "#dangdut - melati"), diambil dari tab Alur
              CutMotions (folder, caption, jumlah, riwayat)
  {video}   = nama video ke-i tanpa ekstensi
  {no}      = nomor putaran ULANGI (1, 2, 3, ...)
  {jumlah}  = jumlah video total (v5.2)
  Video ke-i diambil urut nama A-Z, hormati centang "lewati
  yang sudah terupload" - sama persis dengan urutan baris
  video di situs.
  TIPS v5.2: untuk caption dan jumlah video lebih gampang
  pakai menu "+ VIDEO+CAPTION" daripada placeholder manual.

SIMPAN / BUKA MAKRO:
  - SIMPAN MAKRO  : simpan alur ke file .json (mis.
    "makro_upload_dangdut.json") - bisa disimpan banyak
    makro berbeda.
  - BUKA MAKRO    : muat kembali.
  - MAKRO BARU    : kosongkan alur kerja.
  - Makro aktif OTOMATIS TERSIMPAN setiap ada perubahan ke
    folder data (%LOCALAPPDATA%\CutUploaderPro), jadi saat
    aplikasi dibuka lagi alur terakhir langsung muncul.
  - Menubar BERKAS juga berisi semua perintah ini.

TEMPLATE CUTMOTIONS:
  Klik "TEMPLATE CUTMOTIONS" -> alur A-J versi bebas
  langsung terisi ke Studio (mengambil posisi & pengaturan
  dari tab Alur CutMotions, termasuk blok ULANGI caption
  dan placeholder {caption}). Setelah itu semua langkahnya
  bebas Anda sunting/hapus/tambah - cara paling cepat
  membuat variasi alur CutMotions tanpa mulai dari nol.

CONTOH ALUR SEDERHANA (login situs):
  + CARI GAMBAR  (gambar: tulisan tombol "Masuk", saat
                  ketemu: Klik di gambar)
  + JEDA         2 detik
  + KETIK        email Anda
  + TOMBOL       Tab
  + KETIK        kata sandi
  + TOMBOL       Enter

6. MENISI POSISI KLIK (X, Y)
------------------------------------------------------------
Cara 1 (paling mudah):
  - Klik baris langkahnya di tabel -> panel PROPERTI terbuka.
  - Klik tombol AMBIL (5 dtk), lalu dalam 5 detik arahkan
    mouse ke target di browser dan diamkan.
Cara 2:
  - Isi kotak X dan Y secara manual (boleh diketik).
Cek posisi:
  - Klik LIHAT -> mouse melompat ke titik itu (tanpa klik).
Kondisi halaman saat mengambil posisi (PENTING):
  - A  : halaman Rilis karya, tombol "Jadwal rilis" terlihat.
  - B  : dialog jadwal terbuka, dropdown negara TERTUTUP.
  - C  : daftar negara TERBUKA (bila pakai gambar, C boleh
         titik mana pun di dekat daftar).
  - D,E: form/kalender tanggal terlihat.
  - F,G,H: dialog pilih file Windows terbuka.
  - H2 : tombol "Buka" pada dialog file.
  - I1 : daftar video di situs, baris teratas TERTUTUP.
  - I2/I3: baris teratas TERBUKA (klik dulu Edit-nya manual).
  - J  : halaman discroll sampai BAWAH (Submit terlihat).

7. JEDA ANTAR KLIK
------------------------------------------------------------
Setiap langkah punya 2 macam jeda yang bisa Anda atur sendiri
di panel PROPERTI LANGKAH:
  - JEDA SEBELUM LANGKAH  = waktu tunggu sebelum langkah itu
    dieksekusi (kolom "JEDA" di tabel). Default 1.0 detik.
  - JEDA ANTAR KLIK       = jarak antara klik dengan klik
    berikutnya DI DALAM satu langkah (klik berulang di G/H2/J,
    dan jarak antar tekanan panah bawah di H). Default 0.30
    detik (H: 0.15 detik).
Tombol cepat:
  - "TERAPKAN JEDA ANTAR LANGKAH KE SEMUA LANGKAH" di bagian
    WAKTU mengisi ulang seluruh kolom JEDA dengan satu nilai.
Jeda lain yang tetap ada di bagian WAKTU:
  - MUNDUR SEBELUM MULAI (default 5 detik)
  - JEDA BUKA DIALOG/EDITOR (default 2 detik) - menunggu
    dialog pilih file / editor caption / dropdown terbuka.
  - TUNGGU UPLOAD PER VIDEO (default 60 detik) - dikali jumlah
    video; naikkan kalau internet lambat.
Di Studio Makro, jeda diatur per langkah lewat kolom JEDA
di tabel + MUNDUR SEBELUM MULAI milik Studio.

8. ARTI LANGKAH A-J (SESUAI URUTAN SITUS)
------------------------------------------------------------
  A  Klik "Jadwal rilis / publikasi"
  B  Klik dropdown "NEGARA"
  C  Pilih negara - klik biasa ATAU pencarian gambar
     (lihat bagian 9)
  D  Klik kolom tanggal, tanggal-jam diketik otomatis
     (format 2026-09-10 02:05:01, detik boleh dilewat)
  E  Klik "OKE"
  F  Klik "+ Tambah video"
  G  Klik bebas berulang 0-500x dan/atau scroll 0-50x
     (Turun/Naik). Alternatif: klik=1 lalu scroll=beberapa.
  H  Klik video pertama, tahan SHIFT, panah bawah
     (jumlah video - 1)x  -> 5-20 video terpilih sekaligus
  H2 Klik bebas (tombol "Buka" pada dialog file)
  I  Caption per video: klik Edit -> klik kotak caption ->
     Ctrl+A -> ketik "#dangdut - namafile" -> klik Konfirmasi.
     Ulang otomatis sebanyak jumlah video; posisi klik turun
     sebesar "JARAK ANTAR BARIS" (default 85 piksel) tiap
     baris. Kalau tombol Konfirmasi letaknya sama dengan
     Edit, biarkan I3 kosong (otomatis pakai titik Edit).
  J  Klik "SUBMIT" (boleh dimatikan lewat opsi di langkah J
     kalau mau klik manual setelah mengecek).

Tips penting untuk langkah I:
  - Semua baris video harus terlihat di layar. Kalau 20 video
    tidak muat, kecilkan zoom browser (Ctrl + minus) SEBELUM
    mengambil posisi I1/I2/I3 dan mengukur jarak antar baris.
  - Jangan pindahkan/resize jendela browser setelah posisi
    diambil.

------------------------------------------------------------
9. PENCARIAN GAMBAR (SEMUA LANGKAH, DAN STUDIO MAKRO)
------------------------------------------------------------
Semua langkah A-J (dan salinannya) bisa memakai pencarian
gambar; di Studio Makro tersedia sebagai langkah "+ CARI
GAMBAR" tersendiri:
  1. Klik baris langkahnya di tabel.
  2. Di panel PROPERTI, lihat seksi "PENCARIAN GAMBAR
     (opsional)" (tab CutMotions) atau properti langkah
     CARI GAMBAR (Studio).
  3. Centang "Aktifkan CARI GAMBAR pada langkah ini"
     (tab CutMotions).
  4. PILIH GAMBAR... atau POTONG GAMBAR... (v5.1: layar
     DIBEKUKAN fullscreen, lalu Anda SERET kotak langsung di
     area yang diinginkan - lepas mouse, langsung tersimpan.
     Paling akurat dan paling cepat).
  5. Atur perilakunya:
     SAAT KETEMU      : "Klik di gambar" = klik langsung di
                        pusat gambar yang ditemukan;
                        "Pindah saja"   = mouse hanya DIPINDAH
                        ke gambar, TANPA klik (hover/kalibrasi).
     SAAT TIDAK KETEMU: "Klik titik X,Y" (klik cadangan di
                        titik langkah), "Lewati langkah",
                        atau "Stop alur".
  6. RADIUS & KEMIRIPAN boleh dikosongkan (pakai nilai
     global) atau diisi khusus untuk langkah ini.
  7. TES CARI = coba dulu tanpa menjalankan seluruh alur
     (mouse dipindah ke gambar, tidak diklik).
Titik X,Y langkah tetap penting sebagai PUSAT PENCARIAN
(radius dihitung dari titik itu) dan klik cadangan.

Cara kerja: aplikasi memotong area layar dalam RADIUS piksel
dari titik acuan, lalu mencari gambar referensi (mis.
potongan tulisan "Indonesia") dengan OpenCV (multi-skala,
tahan beda zoom 70-125%). Kalau ketemu, pusat temu yang
diklik/dituju - jadi posisi target boleh bergeser sedikit.

BARU DI V5.4 - REKAM AKSI (REKAMAN MAKRO OTOMATIS):
  Sekarang Anda tidak perlu menyusun langkah satu per satu:
  1. Klik tombol ● REKAM AKSI (merah, di sebelah BERHENTI)
     atau menu Studio > Rekam Aksi -> konfirmasi -> hitung
     mundur 3 detik -> jendela aplikasi tersembunyi dan
     muncul BANNER KECIL "● MEREKAM AKSI" di pojok kanan
     bawah (berisi hitungan aksi; bisa digeser).
  2. Kerjakan aksimu di aplikasi mana pun (browser, form,
     aplikasi Windows). Semua terekam OTOMATIS:
     - Klik kiri      -> langkah KLIK TITIK (posisi + waktu)
       (klik dobel dikenali otomatis jadi "Klik dobel")
     - Klik kanan     -> langkah KLIK TITIK (Klik kanan)
     - Huruf/angka    -> digabung jadi SATU langkah KETIK
       TEKS (mis. "#dangdut - melati")
     - Enter/Tab/Backspace/panah/Home/dll -> langkah TEKAN
       TOMBOL; Ctrl+A/C/V/S/Z juga terekam
     - Gulungan mouse -> digabung jadi SATU langkah SCROLL
       (arah + jumlah gulungan)
     - Jarak waktu antar aksi terekam jadi JEDA antar
       langkah (dibatasi maks 10 detik; Anda bisa ubah).
  3. Tekan F8 (atau ESC) untuk BERHENTI -> jendela tampil
     lagi dan semua hasil rekaman DITAMBAH di akhir alur
     kerja (tidak menimpa langkah lama). Sunting bila perlu,
     lalu JALANKAN (F6) seperti makro biasa.
  Tips:
  - Selagi merekam, JANGAN menekan F8/ESC di aplikasi lain
    kecuali memang mau berhenti merekam.
  - Klik pada banner kecil TIDAK dihitung sebagai aksi;
    banner bisa diseret ke tempat yang tidak menghalangi.
  - Kombinasi Ctrl di luar A/C/V/S/Z tidak terekam (mis.
    Alt+F4); tambahkan manual lewat + TOMBOL bila perlu.
  - Hasil rekaman tersimpan ikut file makro (SIMPAN MAKRO)
    dan bisa disalin/tempel/diurutkan seperti langkah biasa.

BARU DI V5.3 - CARI GAMBAR TANPA X,Y + AREA FOKUS:
  Keluhan lama: "sudah memilih gambar referensi masih tetap
  harus mengisi posisi X,Y". Sekarang TIDAK PERLU lagi:
  - Gambar referensi dicari LALU LANGSUNG DIKLIK begitu
    ketemu (atau hanya dipindah, sesuai pilihan SAAT KETEMU).
  - ISIAN POSISI X,Y dan RADIUS di langkah CARI GAMBAR
    DIHAPUS dari panel properti.
  - Penggantinya: AREA FOKUS (opsional) - daerah persegi
    tempat gambar dicari. Cara isi: klik 'PILIH AREA
    FOKUS...' -> layar dibekukan -> SERET kotak di daerah
    tempat gambar biasanya muncul (mis. hanya daftar negara,
    bukan seluruh halaman) -> lepas, tersimpan. KOSONGKAN =
    cari di seluruh layar.
  Manfaat area fokus: pencarian lebih CEPAT (layar tidak
  di-scan penuh), lebih AKURAT (gambar mirip di luar area
  tidak ikut terdeteksi), dan gambar bisa berpindah posisi
  di dalam area (mis. daftar bergeser sedikit) - tetap
  ketemu, karena yang dicari adalah gambarnya, bukan titik.
  Makro lama v5.2 ke bawah yang masih memakai titik acuan
  X,Y + radius OTOMATIS dikonversi jadi area persegi saat
  dijalankan / dimuat - tidak perlu diubah satu per satu.
  Pilihan SAAT TIDAK KETEMU di Studio kini: Lewati langkah /
  Klik tengah area (pengganti 'Klik titik X,Y' lama) /
  Stop alur. Gambar referensi yang warnanya rata (polos,
  tanpa tulisan) ditolak dengan pesan - potong ulang bagian
  yang berisi tulisan/tombol.

BARU DI V5.2 - ISI TANGGAL-JAM & ISI VIDEO & CAPTION:
  Dua menu baru di toolbar Studio Makro yang menyelesaikan
  keluhan "alur bebas tidak ada yang mengisi kolom tanggal-jam
  dan jumlah video / caption":
  - + TANGGAL-JAM  : satu langkah untuk mengisi kolom
    tanggal-jam rilis di situs. AMBIL NILAI DARI:
    * "Tab CutMotions" - mengikuti kolom TANGGAL & JAM RILIS
      di tab Alur CutMotions (ubah sekali, semua makro ikut).
    * "Tetap (isi sendiri)" - nilai tetap yang Anda ketik di
      properti langkah (format 2026-09-10 02:05:01).
    Bisa KLIK DULU kolomnya sendiri (isi POSISI KLIK DULU)
    atau diletakkan setelah langkah + KLIK kolom tanggal.
    Ctrl+A otomatis ditekan dulu supaya isi lama tertimpa.
  - + VIDEO+CAPTION: satu langkah untuk mengisi data video.
    YANG DIKETIK OTOMATIS:
    * "Jumlah video" - angka JUMLAH VIDEO di tab Alur
      CutMotions (mis. 5).
    * "Caption dasar + nama video" - mis. "#dangdut -
      melati"; kalau ada di dalam blok ULANGI, nama video
      berganti otomatis tiap putaran (melati, rikma, dst).
    * "Nama video saja" - mis. "melati".
    * "Teks sendiri + placeholder" - bebas pakai {caption}
      {video} {no} {jumlah}.
  Contoh alur CutMotions versi bebas yang kini lebih pendek:
    ... -> + KLIK (kolom tanggal) -> + TANGGAL-JAM ->
    + KLIK (OKE) -> ... -> ULANGI MULAI -> + KLIK (Edit) ->
    + KLIK (kotak caption) -> + VIDEO+CAPTION ->
    + KLIK (Konfirmasi) -> ULANGI AKHIR -> ...
  TEMPLATE CUTMOTIONS sekarang memakai keduanya: langkah D
  jadi ISI TANGGAL-JAM dan langkah I2 jadi ISI VIDEO &

PENYEBAB "CARI GAMBAR ERROR" YANG PALING SERING, DAN SOLUSINYA:
  1. Gambar referensi dipotong dari FILE screenshot yang
     ukurannya beda dengan layar asli (mis. screenshot 80%
     atau di-scale Windows).
     SOLUSI: tombol POTONG GAMBAR - layar dibekukan, Anda
     seret kotak langsung di atas tulisannya, lepas -
     tersimpan. Ukurannya dijamin cocok 1:1. Potongan otomatis
     tersimpan ke folder data %LOCALAPPDATA%\CutUploaderPro\
     referensi (bukan folder Program Files yang terkunci
     Windows - dulu ini penyebab error "Errno 13 Permission
     denied" saat SIMPAN AREA; sudah diperbaiki sejak v4.1).
  2. Zoom browser berubah sejak gambar dipotong.
     SOLUSI: pencarian MULTI-SKALA (mencoba 70% - 125%),
     tapi tetap paling akurat bila zoom tetap.
  3. Radius terlalu kecil / ambang kemiripan terlalu tinggi.
     SOLUSI: radius default 300 (boleh sampai 2000),
     kemiripan default 0.80 (turunkan ke 0.70 kalau susah).
  4. Versi EXE buatan sendiri dulu TIDAK membawa OpenCV.
     SOLUSI: build_exe.bat sudah memasukkan semuanya, dan
     Setup.exe/EXE dari rilis GitHub otomatis lengkap.
  5. Pesan error tidak jelas.
     SOLUSI: TES CARI melaporkan penyebabnya secara
     gamblang (mis. "kemiripan terbaik 62%, ambang 80%").
Urutan yang disarankan:
  1. Buka daftar negara di situs.
  2. Klik POTONG GAMBAR -> layar membeku -> seret kotak
     SEMPIT di atas tulisan negaranya (jangan banyak ruang
     kosong) -> lepas mouse, langsung tersimpan.
  3. Klik TES CARI -> mouse harusnya melompat ke tulisan itu.
     Ulangi sampai sukses, baru JALANKAN.

------------------------------------------------------------
9b. SALIN / TEMPEL LANGKAH (CUTMOTIONS)
------------------------------------------------------------
Langkah A-J bisa DIGANDAKAN jadi titik klik tambahan yang
Anda atur sendiri (posisi, jeda, jumlah klik, cari gambar):
  1. Klik baris langkah yang mau disalin.
  2. Klik SALIN LANGKAH (atau Ctrl+C / klik kanan -> Salin).
  3. Klik baris acuan tempat salinan mau disisipkan.
  4. Klik TEMPEL LANGKAH (atau Ctrl+V / klik kanan -> Tempel).
  5. Salinan muncul sebagai baris BIRU bertanda "+" tepat
     setelah baris acuan. Posisinya ikut tersalin - ubah
     dengan AMBIL (5 dtk) atau isi X,Y manual.
  6. Salinan punya pengaturan sendiri: JEDA, JEDA ANTAR KLIK,
     JUMLAH KLIK/SCROLL (untuk G/H2/J), TANGGAL (untuk D),
     dan PENCARIAN GAMBAR sendiri.
  7. HAPUS SALINAN (tombol / Del / klik kanan) menghapus
     salinan terpilih. Langkah bawaan A-J tidak bisa dihapus.

Kapan salinan berguna? Contoh:
  - Butuh 2 titik klik bebas berbeda? Salin G dua kali.
  - Perlu klik "OKE" sekali lagi di posisi lain? Salin E.
  - Perlu isi tanggal kedua? Salin D lalu ubah TANGGAL & JAM.
  - Tombol ke-2 butuh verifikasi gambar? Salin langkah itu,
    aktifkan cari gambar dengan mode "Klik di gambar".
Urutan eksekusi salinan mengikuti posisi baris di tabel:
  salinan ikut FASE langkah asalnya (salinan A-E jalan di
  fase jadwal, salinan F-H2 di fase tambah video, salinan
  I1-I3 ikut LOOP caption per baris, salinan J setelah
  Submit).

Mau kebebasan penuh mengatur urutan? Muat alur A-J ke Studio
lewat tombol "TEMPLATE CUTMOTIONS" - di Studio semua langkah
bisa diurut ulang (NAIK/TURUN), dihapus, dan ditambah bebas.

12. SARAN UJI COBA (PENTING!)
------------------------------------------------------------
1. JUMLAH VIDEO = 1 dulu.
2. G: klik = 1, scroll = 0. H2: klik = 1. J: klik = 1.
3. Jalankan F6 sambil dilihat. Baru naikkan bertahap ke
   5, 10, 20 setelah lancar.
4. Untuk makro Studio: jalankan dengan MUNDUR 5 detik dan
   amati satu per satu; pakai TES CARI sebelum CARI GAMBAR.
5. Darurat: tekan F7/ESC, atau geser mouse ke pojok KIRI
   ATAS layar (failsafe otomatis).

13. TROUBLESHOOTING CEPAT
------------------------------------------------------------
- Klik meleset       : zoom/ukuran jendela browser berubah
                       sejak posisi diambil. Ambil ulang.
- Simpan potongan gambar error "Errno 13 Permission
  denied" (versi lama): sudah diperbaiki sejak v4.1 -
  potongan otomatis tersimpan ke folder data yang bebas
  tulis: %LOCALAPPDATA%\CutUploaderPro\referensi. Kalau
  tetap gagal, muncul dialog pilih lokasi sendiri
  (Documents/Desktop).
- TES CARI gagal     : potong ulang gambar dengan POTONG
                       GAMBAR, perbesar radius, turunkan
                       kemiripan ke 0.70.
- Klik pertama jalan, dialog file tidak terbuka: naikkan
  JEDA BUKA DIALOG/EDITOR menjadi 3-4 detik.
- Upload berhenti di tengah: naikkan TUNGGU UPLOAD PER VIDEO.
- Makro Studio "ULANGI terlalu panjang": ada blok ULANGI
  yang jumlah ulangannya tidak masuk akal (ribuan). Cek
  JUMLAH ULANGAN / centang "ikut jumlah video".
- ULANGI-AKHIR tanpa ULANGI-MULAI (atau sebaliknya):
  aplikasi memperingatkan sebelum jalan - rapikan pasangan
  bloknya di tabel.
- Anti-virus menandai EXE: itu false positive aplikasi tanpa
  tanda tangan digital. Tambahkan pengecualian, atau bangun
  sendiri dengan build_exe.bat.
