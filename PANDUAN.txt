------------------------------------------------------------
1. CARA PASANG DI WINDOWS (TANPA PYTHON!)
------------------------------------------------------------
Ada 3 cara, pilih yang paling gampang:

CARA A - INSTALLER (paling gampang, seperti aplikasi biasa):
  1. Buka  https://github.com/zacrie85/CutUploaderPro/releases
  2. Download  CutUploaderPro-Setup.exe  (rilis v4.0 ke atas)
  3. Kalau muncul biru "Windows protected your PC", klik
     "More info" -> "Run anyway" (ini normal untuk aplikasi
     tanpa tanda tangan digital berbayar).
  4. Next -> Next -> Install -> Finish.
  5. Shortcut otomatis muncul di Start Menu dan Desktop.
  6. Mau dihapus? Lewat Control Panel > Uninstall a program.

CARA B - EXE PORTABEL (tanpa install):
  1. Dari halaman rilis yang sama, download CutUploaderPro.exe
  2. Simpan di folder mana saja, double-click. Selesai.

CARA C - PAKAI PYTHON (untuk yang sudah paham Python):
  1. Install Python (centang "Add Python to PATH")
  2. Double-click JALANKAN.bat  (library dipasang otomatis)
  File EXE/Setup SUDAH menyatukan semua library, jadi cara A/B
  tidak butuh apa-apa lagi.

------------------------------------------------------------
2. PERSIAPAN SEBELUM MENJALANKAN (DILAKUKAN MANUAL)
------------------------------------------------------------
Aplikasi ini TIDAK menyentuh login Anda (email/password tidak
pernah diminta atau disimpan). Lakukan sendiri di browser:
  1. Login ke CutMotions.
  2. Pilih "Versi lama".
  3. Buka menu "Rilis karya".
  4. Diamkan di halaman itu, lalu tekan F6 di aplikasi.

------------------------------------------------------------
3. KENALAN DENGAN TAMPILAN BARU (ALA JITBIT)
------------------------------------------------------------
V4.0 bergaya Jitbit Macro Recorder:
  - TOOLBAR paling atas : JALANKAN (F6), BERHENTI (F7),
    TES CARI GAMBAR, POTONG GAMBAR REFERENSI,
    SIMPAN PROFIL, BUKA PROFIL.
  - VIDEO & CAPTION     : pilih folder video, jumlah video
    (maks 20), caption dasar, pratinjau caption.
  - LANGKAH MAKRO       : tabel berisi langkah A-J.
    KLIK SATU BARIS lalu sunting di panel PROPERTI LANGKAH
    di bawahnya (posisi, jeda, dan opsi khusus).
  - WAKTU & UNGGAH      : mundur, jeda dialog, jeda antar
    langkah, tunggu upload, tombol terapkan jeda ke semua.
  - STATUSBAR bawah     : kabar jalannya makro.

------------------------------------------------------------
4. MENISI POSISI KLIK (X, Y)
------------------------------------------------------------
Cara 1 (paling mudah):
  - Klik baris langkahnya di tabel -> panel PROPERTI terbuka.
  - Klik tombol AMBIL (5 dtk), lalu dalam 5 detik arahkan
    mouse ke target di browser dan diamkan.
Cara 2:
  - Isi kotak X dan Y secara manual (boleh diketik).
Cek posisi:
  - Klik LIHAT -> mouse melompat ke titik itu (tanpa klik).
Kondisi halaman saat mengambil posisi (PENTING):
  - A  : halaman Rilis karya, tombol "Jadwal rilis" terlihat.
  - B  : dialog jadwal terbuka, dropdown negara TERTUTUP.
  - C  : daftar negara TERBUKA (bila pakai gambar, C boleh
         titik mana pun di dekat daftar).
  - D,E: form/kalender tanggal terlihat.
  - F,G,H: dialog pilih file Windows terbuka.
  - H2 : tombol "Buka" pada dialog file.
  - I1 : daftar video di situs, baris teratas TERTUTUP.
  - I2/I3: baris teratas TERBUKA (klik dulu Edit-nya manual).
  - J  : halaman discroll sampai BAWAH (Submit terlihat).

------------------------------------------------------------
5. JEDA ANTAR KLIK (BARU DI V4.0)
------------------------------------------------------------
Sekarang setiap langkah punya 2 macam jeda yang bisa Anda
atur sendiri di panel PROPERTI LANGKAH:
  - JEDA SEBELUM LANGKAH  = waktu tunggu sebelum langkah itu
    dieksekusi (kolom "JEDA" di tabel). Default 1.0 detik.
  - JEDA ANTAR KLIK       = jarak antara klik dengan klik
    berikutnya DI DALAM satu langkah (klik berulang di G/H2/J,
    dan jarak antar tekanan panah bawah di H). Default 0.30
    detik (H: 0.15 detik).
Tombol cepat:
  - "TERAPKAN JEDA ANTAR LANGKAH KE SEMUA LANGKAH" di bagian
    WAKTU mengisi ulang seluruh kolom JEDA dengan satu nilai.
Jeda lain yang tetap ada di bagian WAKTU:
  - MUNDUR SEBELUM MULAI (default 5 detik)
  - JEDA BUKA DIALOG/EDITOR (default 2 detik) - menunggu
    dialog pilih file / editor caption / dropdown terbuka.
  - TUNGGU UPLOAD PER VIDEO (default 60 detik) - dikali jumlah
    video; naikkan kalau internet lambat.
Semua jeda otomatis tersimpan dan ikut dalam profil.

------------------------------------------------------------
6. ARTI LANGKAH A-J (SESUAI URUTAN SITUS)
------------------------------------------------------------
  A  Klik "Jadwal rilis / publikasi"
  B  Klik dropdown "NEGARA"
  C  Pilih negara - klik biasa ATAU pencarian gambar
     (lihat bagian 7)
  D  Klik kolom tanggal, tanggal-jam diketik otomatis
     (format 2026-09-10 02:05:01, detik boleh dilewat)
  E  Klik "OKE"
  F  Klik "+ Tambah video"
  G  Klik bebas berulang 0-500x dan/atau scroll 0-50x
     (Turun/Naik). Alternatif: klik=1 lalu scroll=beberapa.
  H  Klik video pertama, tahan SHIFT, panah bawah
     (jumlah video - 1)x  -> 5-20 video terpilih sekaligus
  H2 Klik bebas (tombol "Buka" pada dialog file)
  I  Caption per video: klik Edit -> klik kotak caption ->
     Ctrl+A -> ketik "#dangdut - namafile" -> klik Konfirmasi.
     Ulang otomatis sebanyak jumlah video; posisi klik turun
     sebesar "JARAK ANTAR BARIS" (default 85 piksel) tiap
     baris. Kalau tombol Konfirmasi letaknya sama dengan
     Edit, biarkan I3 kosong (otomatis pakai titik Edit).
  J  Klik "SUBMIT" (boleh dimatikan lewat opsi di langkah J
     kalau mau klik manual setelah mengecek).

Tips penting untuk langkah I:
  - Semua baris video harus terlihat di layar. Kalau 20 video
    tidak muat, kecilkan zoom browser (Ctrl + minus) SEBELUM
    mengambil posisi I1/I2/I3 dan mengukur jarak antar baris.
  - Jangan pindahkan/resize jendela browser setelah posisi
    diambil.

------------------------------------------------------------
7. PENCARIAN GAMBAR (LANGKAH C) - DAN PERBAIKANNYA
------------------------------------------------------------
Cara kerja: aplikasi memotong area layar dalam RADIUS piksel
dari titik C, lalu mencari gambar referensi Anda (mis.
potongan tulisan "Indonesia") dengan OpenCV. Kalau ketemu,
titik temu yang diklik - jadi posisi daftar negara boleh
bergeser sedikit.

PENYEBAB "CARI GAMBAR ERROR" YANG PALING SERING, DAN SOLUSINYA:
  1. Gambar referensi dipotong dari FILE screenshot yang
     ukurannya beda dengan layar asli (mis. screenshot 80%
     atau di-scale Windows).
     SOLUSI BARU v4.0: tombol POTONG GAMBAR REFERENSI -
     aplikasi screenshot layar yang HIDUP, Anda seret kotak
     di atas tulisan negaranya, SIMPAN. Ukurannya dijamin
     cocok 1:1.
  2. Zoom browser berubah sejak gambar dipotong.
     SOLUSI v4.0: pencarian sekarang MULTI-SKALA (mencoba
     70% - 125%), tapi tetap paling akurat bila zoom tetap.
  3. Radius terlalu kecil / ambang kemiripan terlalu tinggi.
     SOLUSI: radius default 300 (boleh sampai 2000),
     kemiripan default 0.80 (turunkan ke 0.70 kalau susah).
  4. Versi EXE buatan sendiri dulu TIDAK membawa OpenCV
     (build_exe.bat lama mengecualikan PIL/numpy).
     SOLUSI: build_exe.bat v4.0 sudah memasukkan semuanya,
     dan Setup.exe/EXE dari rilis GitHub otomatis lengkap.
  5. Pesan error dulu tidak jelas.
     SOLUSI: sekarang TES CARI melaporkan penyebabnya secara
     gamblang (mis. "kemiripan terbaik 62%, ambang 80%").
Urutan yang disarankan:
  1. Buka daftar negara di situs.
  2. Klik POTONG GAMBAR -> seret kotak SEMPIT di atas tulisan
     negaranya (jangan banyak ruang kosong) -> SIMPAN AREA.
  3. Klik TES CARI GAMBAR -> mouse harusnya melompat ke
     tulisan itu. Ulangi sampai sukses, baru JALANKAN.

------------------------------------------------------------
8. PROFIL MAKRO (PENGGANTI DAFTAR BROWSER)
------------------------------------------------------------
Karena posisinya kini banyak (A-J), v4.0 memakai cara Jitbit:
  - SIMPAN PROFIL  : simpan semua posisi + jeda + pengaturan
    ke satu file .json (mis. "profil_chrome_akun1.json").
  - BUKA PROFIL    : muat kembali. Mau pakai 2 browser/akun?
    Simpan 2 profil, buka sesuai kebutuhan.
  - Pengaturan terakhir otomatis tersimpan juga
    (cutuploader_settings.json di folder aplikasi).

------------------------------------------------------------
9. RIWAYAT & LEWATI YANG SUDAH TERUPLOAD
------------------------------------------------------------
- Setelah batch selesai, daftar video dicatat ke
  cutuploader_riwayat.json (urut baris situs).
- Centang "Lewati video yang sudah pernah terupload" supaya
  batch berikutnya memakai video yang belum pernah diupload.
- Kalau di tengah jalan dihentikan (F7) saat menunggu upload,
  jalankan F6 lagi: semua video sudah masuk -> aplikasi
  menawarkan LANJUT KE FASE CAPTION.
- Alat > Lihat Riwayat / Bersihkan Riwayat folder ini.

------------------------------------------------------------
10. SARAN UJI COBA (PENTING!)
------------------------------------------------------------
1. JUMLAH VIDEO = 1 dulu.
2. G: klik = 1, scroll = 0. H2: klik = 1. J: klik = 1.
3. Jalankan F6 sambil dilihat. Baru naikkan bertahap ke
   5, 10, 20 setelah lancar.
4. Darurat: tekan F7/ESC, atau geser mouse ke pojok KIRI
   ATAS layar (failsafe otomatis).

------------------------------------------------------------
11. TROUBLESHOOTING CEPAT
------------------------------------------------------------
- Klik meleset       : zoom/ukuran jendela browser berubah
                       sejak posisi diambil. Ambil ulang.
- TES CARI gagal     : potong ulang gambar dengan POTONG
                       GAMBAR, perbesar radius, turunkan
                       kemiripan ke 0.70.
- Klik pertama jalan, dialog file tidak terbuka: naikkan
  JEDA BUKA DIALOG/EDITOR menjadi 3-4 detik.
- Upload berhenti di tengah: naikkan TUNGGU UPLOAD PER VIDEO.
- Anti-virus menandai EXE: itu false positive aplikasi tanpa
  tanda tangan digital. Tambahkan pengecualian, atau bangun
  sendiri dengan build_exe.bat.
